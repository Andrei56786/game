# Слово короля на Godot 4.7 — срез «Двор» 0.1

Начало переноса игры на Godot (план — `notes/plan-v4.md`). Мир рисуется кодом в пикселях 640×360 и увеличивается в целое число раз; шрифт — тот же книжный, что в браузерной версии (`src/fontdata.js`).

- **Заставка** — ночной замок, луна, звёзды, факелы с искрами.
- **Двор** 48×34 клетки: донжон с башнями, знамёнами и аркой ворот, казармы, конюшня, колодец, ристалище с чучелом, сад; лес за северной стеной.
- **Время**: 1 секунда — 4 игровые минуты, Пробел — пауза, 1–3 — скорость. Сумерки и ночь — `CanvasModulate`, факелы — `PointLight2D` и частицы, окна светятся.
- **Люди**: сенешаль Освальд, стражник Бран (ночью на посту), служанка Эльза, конюх Тобиас, ловчий Мартин — у каждого распорядок по часам, ходят по `AStarGrid2D`, ночью уходят в дома. E — заговорить.

| Файл | Что там |
|---|---|
| `scripts/game.gd` | общее состояние (автозагрузка `Game`): часы, день и ночь, шум, шрифт |
| `scripts/pix.gd` | пиксель-арт из кода: человечки 12×20 в 4 стороны по 4 кадра, шапки, плащи, платья; радиальный свет |
| `scripts/title.gd` | заставка |
| `scripts/court.gd` | двор: карта, земля кусками 8×8 клеток (на одну картинку действует не больше 16 огней), постройки, свет, люди, разговоры, самопроверка |
| `scripts/main.gd` | заставка ↔ двор; `-- --selftest`; в вебе — `window.slovo('команда')` для тестов |
| `build.sh` | шрифт → импорт → самопроверка → экспорт в `build/web` и `build/win/slovo.exe` (`sh build.sh test` — только проверка) |
| `test_web.mjs` | веб-сборка в Chromium без окна: заставка, двор днём, в сумерках и ночью, разговор, ходьба; ошибки консоли — провал; снимки в `build/shots/` |
