# Слово короля на Godot 4.7 — срез «Двор» 0.2

Начало переноса игры на Godot (план — `notes/plan-v4.md`). С версии 0.2 срез берёт графику и данные прямо из HTML-версии: тот же замок, те же люди, тот же масштаб. Мир — 640×360 точек, увеличивается в целое число раз (×2 в окне 1280×720); в кадре 320×180 точек мира, человек — 16×32.

- **Заставка** — как в HTML: закат, замок на холме, пиксельное «СЛОВО КОРОЛЯ», деревянные кнопки; «Управление» и выбор шрифта (книжный или пиксельный, запоминается).
- **Замок** — все 7 мест HTML-версии: тронный зал с покоями, верхний этаж, подземелье, большой зал, часовня, двор и лес; двери между ними, комнаты с названиями.
- **Времена года** — вид двора и леса по дню года, как в HTML: оттепель, цветение, лето, три осени, снег (84 дня в году, по 21 на сезон).
- **Свет** — карта света как в HTML: окружающий свет по часам, огни, окна, лучи из окон, свечение пламени; ночью виньетка, вокруг короля в покоях — тёплый круг.
- **Люди** — 35 придворных и слуг из HTML с их распорядком, постелями, постами и речами; 20 животных; облачка реплик, окно разговора с портретом и печатающимся текстом.
- **Король** ходит (WASD/стрелки, Shift — тише, или щелчок мышью), садится на трон, спит в постели, пьёт из колодца, смотрит на кузню. Z или колесо — масштаб, Пробел — пауза, 1–3 — скорость, H — подсказка, Esc — на заставку.

| Файл | Что там |
|---|---|
| `tools/export.mjs` | выгрузка из `dist/index.html` (Playwright): фоны мест по видам года, атлас спрайтов, люди 16×32 в 4 стороны, портреты, животные, значки (и чёткие для книжного шрифта), пиксельные шрифты (BMFont), фон заставки; карта проходимости, двери, места, огни, окна, распорядки и реплики → `art/` (в git не хранится) |
| `scripts/game.gd` | автозагрузка `Game`: часы как в HTML (сутки, сезоны, долгие летние вечера), дата, книжный шрифт |
| `scripts/art.gd` | автозагрузка `Art`: данные и атлас из `art/`, текст как `txt`/`tw` в HTML (книжный Slovo Serif или пиксельный), деревянные панели и кнопки |
| `scripts/court.gd` | места, `AStarGrid2D`, двери с затемнением, свет, частицы, король, действия, команды тестов, самопроверка |
| `scripts/people.gd` | люди: распорядок, путь между местами, сон, посты, сидения |
| `scripts/hud.gd` | верхняя строка, подсказка «E», облачка, окно разговора, тосты |
| `scripts/title.gd` | заставка |
| `scripts/main.gd` | заставка ↔ двор; `-- --selftest`; в вебе — `window.slovo('команда')` для тестов |
| `build.sh` | HTML-сборка и выгрузка графики → импорт → самопроверка → экспорт в `build/web` и `build/win/slovo.exe` (`sh build.sh test` — только проверка) |
| `test_web.mjs` | веб-сборка в Chromium без окна: заставка и «Управление», тронный зал и двор днём, вид двора летом, осенью и зимой, сумерки, ночь, разговор, ходьба, масштаб; ошибки консоли — провал; снимки в `build/shots/` |
