# Слово короля

Браузерная стратегия о короле, который правит словом: двор и Малый совет, династия и знать, держава и дипломатия, товарная экономика, жизнь замка (охота, пиры, турниры) и поездки по державе, глубокие битвы в духе Сунь-цзы. Сейчас это прототип **v3.3** на HTML и JavaScript без зависимостей; дальше — перенос на Godot 4.

## Запуск

```bash
python3 tools/build.py            # → dist/index.html — один файл, открывается в браузере
python3 tools/build.py out.html   # собрать в другой файл
```

`dist/index.html#court777` — сразу новая игра при дворе (777 — зерно мира), `#courttut777` — то же с обучением.

## Устройство

| Папка | Что там |
|---|---|
| `src/` | 55 модулей игры. Порядок склейки — `ORDER` в `tools/build.py`; всё оборачивается в одну IIFE. Каждый файл — меньше ~55 КБ |
| `tools/` | сборка (`build.py`, `head.html`, `tail.html`), автотесты в браузере без окна (`drive.mjs`, `smoke.mjs`), замер генерации мира (`genbench.mjs`), точечные правки (`patch.py`), подготовка отправки в GitHub (`ghpush.py`) |
| `tests/` | сценарии для `drive.mjs`: `smoke.json` (300 дней), `econ.json` (год экономики), `econui.json` (окна экономики), `play.json`, `map.json`, `path.json`, сцены v3.3 — `castle.json`, `hunt.json`, `feast.json`, `chapel.json`, `proj.json` и другие |
| `notes/` | `vyzhimka-chata.md` — подробная выжимка: замысел, что сделано, техника, баланс, дорожная карта; `prilozheniya.md` — приложения к ней |

## Тесты

```bash
python3 tools/build.py
node tools/drive.mjs "file://$PWD/dist/index.html#court777" tests/smoke.json
```

Нужны Node 18+ и пакет `playwright` с Chromium. Скриншоты тестов пишутся в `shots/` (в git не хранятся).

## Версии

- **v3.3** — замок, охота и поездки: столица шире (восточный двор, верхний этаж, темница), 12 строек, королевская охота, пиры и турниры, часовня и обедня, книги, узники; въезд в деревни и города (в том числе неузнанным) и визиты в свои и чужие замки.
- **v3.2** — большая карта (×5 по площади, 85 провинций, км и дни пути) и товарная экономика (14 товаров, ремёсла, караваны, окна «Казна», «Хозяйство», «Товары»).
- **v3.1** — доводка битв, двора и снабжения.
- **v3** — двор и королевство, 6 правок по отзыву, глубокие битвы.
