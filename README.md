# Слово короля

Браузерная стратегия о жизни одного короля, который правит словом: двор и Малый совет, династия и знать, держава и дипломатия, товарная экономика, жизнь замка (охота, пиры, турниры) и поездки по державе, тяжёлые походы и глубокие битвы в духе Сунь-цзы. Летопись записывает дела короля; после его смерти наследник начинает новую главу. Сейчас это прототип **v3.5** на HTML и JavaScript без зависимостей; дальше — перенос на Godot 4.

## Запуск

```bash
python3 tools/build.py            # → dist/index.html — один файл, открывается в браузере
python3 tools/build.py out.html   # собрать в другой файл
```

`dist/index.html#court777` — сразу новая игра при дворе (777 — зерно мира), `#courttut777` — то же с обучением.

## Устройство

| Папка | Что там |
|---|---|
| `src/` | 68 модулей игры. Порядок склейки — `ORDER` в `tools/build.py`; всё оборачивается в одну IIFE. Каждый файл — меньше ~55 КБ |
| `tools/` | сборка (`build.py`, `head.html`, `tail.html`), автотесты в браузере без окна (`drive.mjs`, `smoke.mjs`), замер генерации мира (`genbench.mjs`), точечные правки (`patch.py`), подготовка отправки в GitHub (`ghpush.py`) |
| `tests/` | сценарии для `drive.mjs` (`save.json` — сохранение и загрузка): `smoke.json` (300 дней), `econ.json` (год экономики), `econui.json` (окна экономики), `play.json`, `map.json`, `path.json`, сцены v3.3 — `castle.json`, `hunt.json`, `feast.json`, `chapel.json`, `proj.json`, сцены v3.4 — `supply.json` (снабженец и посыльные), `hunt3.json` (оружие, кровавый след, трофеи, белый олень), сцены v3.5 — `hurt.json`, `hurt2.json` (ранение, носилки, постель, дни лечения), `herald.json`, `herald2.json` (объявление войны герольдом), `march.json` (распутица, мороз, броды, сорок дней ополчения), `reign.json` (летопись, эпохи, новая глава) и другие |
| `notes/` | `vyzhimka-chata.md` — подробная выжимка: замысел, что сделано, техника, баланс, дорожная карта; `prilozheniya.md` — приложения к ней |

## Тесты

```bash
npm install && npx playwright install chromium   # один раз
npm test            # сборка и все сценарии, кроме долгих стендов баланса
npm run test:all    # вместе со стендами баланса (hl_*, q*)
node tools/runtests.mjs smoke save                  # только названные сценарии
node tools/drive.mjs "file://$PWD/dist/index.html#court777" tests/smoke.json   # один сценарий с выводом
```

Нужны Node 18+, Python 3 и `playwright` с Chromium. Сценарий не проходит, если упал шаг, не выполнилась проверка `{"expect": …}`, на странице была ошибка или в выводе есть непустой список `"errs"`. На каждый PR и пуш в `main` тесты запускает GitHub Actions (`.github/workflows/tests.yml`). Скриншоты тестов пишутся в `shots/` (в git не хранятся).

Одно и то же зерно мира даёт одну и ту же игру: генератор случайностей засевается от зерна, а его состояние хранится в сохранении (`tests/save.json` это проверяет).

## Версии

- **v3.5** — жизнь одного короля: летопись правления (T) с прозвищем по делам; смерть короля закрывает главу, наследник начинает новую со своим заветом; эпохи (Раннее, Высокое, Позднее Средневековье) открывают новые знания со временем. Реализм: война объявляется герольдом с подписанной грамотой, и он скачет к врагу по суше; кабан бросается не сразу, ранение лечат (носилки, постель, дни болезни); карта мира в 2,25 раза больше; походы трудные: распутица, мороз, переправы, сорок дней службы ополчения. Тихие шаги, 19 длинных пьес по месту и событию, птицы и звуки вокруг, микшер громкости. Времена года во дворе, в лесу, в деревне и на карте. Окна проще, меньше текста.
- **v3.4** — правки по отзыву: кони и калитки у загонов, шатры и стройки по этапам (видно, как растёт здание), портрет короля, картины вместо окон, лестницы, новая музыка; вход в темницу у дороги, турнир без трибун; снабженец и посыльные (окно O: «подготовить поход на N дней»), ручьи и родники; все звери и птицы перерисованы (шаг, бег, пастьба, окрасы, зимний мех); охота с луком, сулицами и рогатиной, кровавым следом, ветром, трофеями и белым оленем.
- **v3.3** — замок, охота и поездки: столица шире (восточный двор, верхний этаж, темница), 12 строек, королевская охота, пиры и турниры, часовня и обедня, книги, узники; въезд в деревни и города (в том числе неузнанным) и визиты в свои и чужие замки.
- **v3.2** — большая карта (×5 по площади, 85 провинций, км и дни пути) и товарная экономика (14 товаров, ремёсла, караваны, окна «Казна», «Хозяйство», «Товары»).
- **v3.1** — доводка битв, двора и снабжения.
- **v3** — двор и королевство, 6 правок по отзыву, глубокие битвы.
