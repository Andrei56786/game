# Слово короля

Браузерная стратегия о жизни одного короля, который правит словом: двор и Малый совет, династия и знать, держава и дипломатия, товарная экономика, жизнь замка (охота, пиры, турниры) и поездки по державе, тяжёлые походы и глубокие битвы в духе Сунь-цзы. Летопись записывает дела короля; после его смерти наследник начинает новую главу. Сейчас это прототип **v3.7** на HTML и JavaScript без зависимостей; дальше — перенос на Godot 4.

## Запуск

```bash
python3 tools/build.py            # → dist/index.html — один файл, открывается в браузере
python3 tools/build.py out.html   # собрать в другой файл
```

`dist/index.html#court777` — сразу новая игра при дворе (777 — зерно мира), `#courttut777` — то же с обучением.

### Windows

Готовые `.exe` (Windows 10/11, 64 бит, без установки) — на странице [Releases → «Слово короля для Windows»](https://github.com/Andrei56786/game/releases/tag/windows); после каждого слияния в `main` их пересобирает GitHub Actions (`.github/workflows/windows.yml`).

- `Slovo-korolya-<версия>.exe` — вся игра в своём окне (Electron, папка `desktop/`). F11 или Alt+Enter — во весь экран; сохранения — в `%APPDATA%\Slovo korolya`. Собрать самому на Windows: `python tools/build.py`, затем в `desktop/` — `npm install` и `npm run win` (→ `desktop/out/`).
- `Slovo-korolya-Dvor-<версия>-Godot.exe` — срез 0.4 версии на Godot 4.7 (папка `godot/slovo/`): заставка, живой замок с графикой и людьми из HTML-версии и карта королевства (тот же мир, рисует видеокарта, через весь год) с туманом войны, войсками и подсказками — королевство посчитано так же, как в HTML. Собрать: `sh godot/slovo/build.sh` (Godot 4.7.2 и шаблоны экспорта — `notes/plan-v4.md`), проверить веб-сборку: `node godot/slovo/test_web.mjs`.

Файлы не подписаны: если SmartScreen предупредит о неизвестном издателе — «Подробнее» → «Выполнить в любом случае».

## Тесты

```bash
npm install && npx playwright install chromium   # один раз
npm test            # сборка и все сценарии, кроме долгих стендов баланса
npm run test:all    # вместе со стендами баланса (hl_*, q*)
node tools/runtests.mjs smoke save                  # только названные сценарии
node tools/drive.mjs "file://$PWD/dist/index.html#court777" tests/smoke.json   # один сценарий с выводом
```

Нужны Node 18+, Python 3 и `playwright` с Chromium. Сценарий не проходит, если упал шаг, не выполнилась проверка `{"expect": …}`, на странице была ошибка или в выводе есть непустой список `"errs"`. На каждый PR и пуш в `main` тесты запускает GitHub Actions (`.github/workflows/tests.yml`), там же собираются и проверяются сборки для Windows (`windows.yml`: Electron на `windows-latest`; Godot — самопроверка двора и королевства, сверка генератора мира и новой игры с HTML, веб-сборка в Chromium со снимками заставки, дня, сумерек, ночи, времён года, разговора, карты королевства, тумана войны и войск). Скриншоты тестов пишутся в `shots/` (в git не хранятся).

Одно и то же зерно мира даёт одну и ту же игру: генератор случайностей засевается от зерна, а его состояние хранится в сохранении (`tests/save.json` это проверяет).

## Версии

- **v3.7** — «Враг верит, а не знает»: каждая держава хранит свою картину войск короны (где, какими и чьими глазами их видели — разъезды, крепости, слухи с дорог, шпион при нашем дворе); её полководцы бегут, преследуют и выбирают цели только по этой картине. Уловки: ложные костры, приказ лорду «Ложный марш…» и знамёна с барабанами у войска короля (враг стягивает войска сторожить крепость, разъезд вблизи раскрывает уловку), притворное отступление (догнавший растянул строй), чучела на стенах, поручения Ока — подложное письмо, слухи о нашей силе или слабости, перехват гонцов с подменой приказа. Враг отвечает тем же: хитрые полководцы жгут ложные костры, затаиваются в лесу и шлют слабейшее войско в ложный марш. Окно «Разведка и обман» (I): что мы знаем, что думает враг, уловки, журнал; призраки на карте — последнее донесение о чужом войске.
- **v3.6** — правки по отзыву: книжный шрифт (чёткий текст, холст в разрешении экрана; пиксельный — переключателем в меню); магистр сам выбирает знания и копит вдохновение, знания будущих эпох можно раньше срока; пташки Ока следят за советом и кандидатами, у придворных скрытые мотивы, вкладка «Кандидаты»; королевские амбары (оброк зерном дважды в год, неприкосновенный запас, подводы, голодные годы); проход во дворе между казармами и башней; охота со своим луком (натянуть и отпустить), лес вдвое больше, разделиться с ловчим; советники подсказывают при первом входе в комнату, здание, лес и к столу карт; болезни и лекарь (лечение, заразность, смерть от горячки после ран); 14 новых пьес (комнаты, весна, болезнь); значки нарисованы заново для книжного шрифта.
- **v3.5** — жизнь одного короля: летопись правления (T) с прозвищем по делам; смерть короля закрывает главу, наследник начинает новую со своим заветом; эпохи (Раннее, Высокое, Позднее Средневековье) открывают новые знания со временем. Реализм: война объявляется герольдом с подписанной грамотой, и он скачет к врагу по суше; кабан бросается не сразу, ранение лечат (носилки, постель, дни болезни); карта мира в 2,25 раза больше; походы трудные: распутица, мороз, переправы, сорок дней службы ополчения. Тихие шаги, 19 длинных пьес по месту и событию, птицы и звуки вокруг, микшер громкости. Времена года во дворе, в лесу, в деревне и на карте. Окна проще, меньше текста.
- **v3.4** — правки по отзыву: кони и калитки у загонов, шатры и стройки по этапам (видно, как растёт здание), портрет короля, картины вместо окон, лестницы, новая музыка; вход в темницу у дороги, турнир без трибун; снабженец и посыльные (окно O: «подготовить поход на N дней»), ручьи и родники; все звери и птицы перерисованы (шаг, бег, пастьба, окрасы, зимний мех); охота с луком, сулицами и рогатиной, кровавым следом, ветром, трофеями и белым оленем.
- **v3.3** — замок, охота и поездки: столица шире (восточный двор, верхний этаж, темница), 12 строек, королевская охота, пиры и турниры, часовня и обедня, книги, узники; въезд в деревни и города (в том числе неузнанным) и визиты в свои и чужие замки.
- **v3.2** — большая карта (×5 по площади, 85 провинций, км и дни пути) и товарная экономика (14 товаров, ремёсла, караваны, окна «Казна», «Хозяйство», «Товары»).
- **v3.1** — доводка битв, двора и снабжения.
- **v3** — двор и королевство, 6 правок по отзыву, глубокие битвы.
